GUIDE

Which files go where?

Gallery & digital edition

Upload your best JPG, PNG or WebP, or a Smart ZIP with separate MASTER, DIGITAL/RETINA, PRINT/300DPI and WEB/PORTFOLIO versions. Private versions go to art-originals; reduced public previews go to art-previews. Choose Attach or replace an existing artwork's source files if the piece is already listed.

Uploading does not enable sales. A private master must be checked for artwork ID, real pixel dimensions, quality, digital licence and payment delivery before a digital edition can be sold.

Physical print & backup

Keep a second full-resolution copy in your own backed-up archive. A print provider needs the actual print-ready image, correct crop, dimensions, colour profile and product setup. The public preview is not a print file.

Physical printing is not connected to this admin yet. Do not offer paper, canvas, signatures, limited editions, shipping or print prices until your provider and product details are confirmed.

How do I upload a print-quality file for an artwork that is already in the gallery?

Select Attach or replace an existing artwork's source files, choose the artwork, then upload either one image or one Smart ZIP containing its versions. Master/original, digital-sale and print files are stored privately. If the ZIP contains an explicitly named WEB/PORTFOLIO version, that version becomes the public preview only when the artwork is not already sale-enabled. Title, description and category stay unchanged. Verified sale masters are protected against replacement. JPG/PNG/WebP images must be 50 MB or less; for TIFF, PDF or larger print files use your own backup and the print provider's secure uploader. Setting a file to 300 DPI does not create missing image detail.

A master record does not prove that the Storage file exists. The file-check panel compares the record with the actual private object. A matching object is still not proof of print resolution, native detail or approved sales.

01

Choose files

Add JPG, PNG or WebP files, or one ZIP package. ZIPs are extracted in your browser; the archive itself is never published. Smart ZIP recognizes multiple versions of the same artwork and routes them by role instead of throwing the other versions away.

Smart ZIP · automatic file placement

Put the role in either the folder name or filename. Supported roles are MASTER/ORIGINAL, DIGITAL/RETINA/2X, PRINT/300DPI, and WEB/PORTFOLIO/PREVIEW. Example:

Midnight-City/
  master/Midnight-City_MASTER.png
  digital/Midnight-City_RETINA.jpg
  print/Midnight-City_PRINT_300DPI.jpg
  web/Midnight-City_WEB.jpg

The master, digital and print versions remain private in art-originals. The web version is converted to reduced public WebP view/thumb files in art-previews. If no explicit master is supplied, the best available private version is used as the unverified master fallback.

Up to 30 works per batch · 250 MB per ZIP · 50 MB per image. A package may contain up to four recognized versions per artwork. For larger archives, split the ZIP.

02

Choose the category

These values are always your decision. The selected values are applied to the current batch, and you can change them for individual images below.

Digital sales are not automatically activated. Uploaded masters stay private until purchase and delivery are separately verified.

03

Review each artwork

Artwork titles are English only. An English title from the ZIP or filename is kept in English; a Norwegian source title is converted to English before review. Titles, descriptions, collections and styles can then be corrected individually. Describe what is actually visible in the artwork, then its possible emotional meaning. Duplicate filenames are grouped; if a filename does not identify the correct existing work, choose it manually.
